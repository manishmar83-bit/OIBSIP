# 🌸 Iris Flower Classification

This project was completed as **Task 1** during my Machine Learning internship with **Oasis Infobyte**.

## 📌 Project Overview

The objective of this project is to build a Machine Learning model that classifies iris flowers into three different species:

* Setosa
* Versicolor
* Virginica

The classification is performed using measurements such as sepal length, sepal width, petal length, and petal width.

## 🔍 Project Workflow

* Data loading and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Correlation analysis
* Train-test splitting
* Machine Learning model training
* Model evaluation

## 🤖 Machine Learning Models

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Random Forest Classifier

## 📊 Evaluation Metrics

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
