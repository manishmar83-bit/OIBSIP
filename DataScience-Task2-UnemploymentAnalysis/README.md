# 📊 Unemployment Analysis with Python

This project was completed as **Task 2** during my Data Analytics and Machine Learning internship with **Oasis Infobyte**.

## 📌 Project Overview

The objective of this project is to analyze unemployment data in India and identify **regional and monthly trends** in unemployment rates.

The analysis also includes a descriptive comparison of unemployment around the **COVID-19 period**.

## 🔍 Project Workflow

* Data loading
* Dataset inspection
* Data cleaning and preprocessing
* Missing value checking
* Data type conversion
* Exploratory Data Analysis (EDA)
* Regional analysis
* Monthly trend analysis
* Data visualization
* COVID-period comparison

## 📈 Analysis Performed

The project explores:

* Unemployment trends over time
* Differences between regions
* Monthly unemployment patterns
* Changes around the COVID-19 period
* Regional unemployment averages

## 📊 Visualizations

The analysis uses charts and graphs to identify important patterns and trends in the dataset.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
