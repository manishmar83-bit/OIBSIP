# 🚗 Car Price Prediction

This project was completed as **Task 3** during my Machine Learning internship with **Oasis Infobyte**.

## 📌 Project Overview

The objective of this project is to build a Machine Learning model that predicts the **selling price of used cars** based on different vehicle features.

The project includes data preprocessing, feature engineering, exploratory data analysis, model building, and evaluation.

## 🔍 Project Workflow

* Data loading and inspection
* Data cleaning and preprocessing
* Handling categorical data
* Feature engineering
* Exploratory Data Analysis (EDA)
* Data visualization
* Model training
* Model evaluation

## ⚙️ Feature Engineering

The project includes:

* Calculating **Car Age** from the manufacturing year
* Extracting the **Car Brand** from the car name
* Processing categorical features such as fuel type, seller type, transmission, and owner

## 🤖 Machine Learning Models

* Linear Regression
* Random Forest Regression

## 📊 Evaluation Metrics

The models were evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score
